# CY-QCM

Pour lancer le programme dans le terminal : make puis ./exec

Pour supprimer les .o et l'executable : make clean

Si vous choisissez le mode prof : mot de passe par defaut 0067

Mode élève :  _choisir un qcm puis le faire avec score à la fin

Mode prof :   _créer un qcm de A a Z
              _changer le mot de passe
              _afficher un qcm entier
